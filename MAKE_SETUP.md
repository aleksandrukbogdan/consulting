# Настройка вебхука для Make.com

## Шаг 1: Создание сценария в Make.com

1. Войдите в ваш аккаунт Make.com
2. Создайте новый сценарий
3. Добавьте триггер "Webhook" → "Custom webhook"
4. Скопируйте URL вебхука (будет выглядеть как `https://hook.eu1.make.com/xxxxxxxx`)

## Шаг 2: Настройка переменной окружения

Замените URL в файле `app.py` на ваш реальный URL:

```python
MAKE_WEBHOOK_URL = 'https://hook.eu1.make.com/ваш-реальный-url'
```

Или установите переменную окружения:

```bash
export MAKE_WEBHOOK_URL="https://hook.eu1.make.com/ваш-реальный-url"
```

## Шаг 3: Настройка обработки данных в Make.com

В сценарии Make.com добавьте модули для обработки входящих данных:

### Структура данных, которые отправляет сайт:

```json
{
  "name": "Имя пользователя",
  "email": "email@example.com", 
  "message": "Текст сообщения",
  "timestamp": "IP адрес",
  "user_agent": "Информация о браузере",
  "source": "ScienceDevice Website"
}
```

### Рекомендуемые модули в Make.com:

1. **Webhook** (триггер) - получает данные
2. **Email** - отправка уведомления на email
3. **Google Sheets** - сохранение в таблицу (опционально)
4. **Slack** - уведомление в Slack (опционально)

## Шаг 4: Тестирование

1. Запустите Flask приложение:
   ```bash
   python app.py
   ```

2. Откройте сайт и заполните форму обратной связи
3. Проверьте, что данные приходят в Make.com
4. Настройте дальнейшую обработку (отправка email, сохранение в БД и т.д.)

## Дополнительные настройки

### Безопасность
- Добавьте проверку токена в Make.com
- Настройте CORS если необходимо
- Добавьте rate limiting для предотвращения спама

### Логирование
- Все отправки логируются в консоль Flask
- Ошибки отправки также логируются

### Расширение функциональности
- Добавьте поля для номера телефона
- Настройте автоматические ответы
- Интегрируйте с CRM системами
